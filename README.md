# goit-pycore-hw-08

Тема 12. Фінальна домашня робота: «Серіалізація та копіювання об'єктів у Python».

Консольний бот із попередньої роботи тепер зберігає адресну книгу через `pickle` перед завершенням і відновлює її при наступному запуску. Зберігається весь об'єкт `AddressBook`: імена, усі телефони та дні народження контактів.

## Файли

- [address_book.py](address_book.py) — класи `Field`, `Name`, `Phone`, `Birthday`, `Record`, `AddressBook` та найближчі привітання.
- [storage.py](storage.py) — функції `save_data` і `load_data`.
- [main.py](main.py) — обробники команд та запуск бота зі збереженням даних.
- [tests/test_persistence.py](tests/test_persistence.py) — перевірки серіалізації, завершення роботи та відновлення в новому процесі.

## Запуск

Потрібен Python 3.10 або новіший. Сторонніх залежностей немає.

```console
python main.py
```

У Linux/macOS за потреби використовуйте `python3`.

## Як працює збереження

1. При запуску `load_data()` читає `addressbook.pkl`. Якщо файлу ще немає, створюється порожня адресна книга.
2. Команди змінюють завантажену книгу.
3. Після `exit`, `close`, завершення введення або `Ctrl+C` функція `save_data()` зберігає книгу у двійковому форматі через `pickle.dump` з `pickle.HIGHEST_PROTOCOL`.
4. Наступний запуск відновлює об'єкти через `pickle.load`, включно з телефонами та датами народження.

За замовчуванням файл лежить **поруч із `main.py`**, тому бот знаходить ту саму книгу навіть при запуску з іншої папки. Обом функціям можна передати інший шлях: `save_data(book, "my_book.pkl")` і `load_data("my_book.pkl")`.

Запис спочатку йде в тимчасовий файл у тій самій папці; попередній файл замінюється лише після успішної серіалізації. Якщо завантаження не вдалося або файл містить інший тип об'єкта, бот повідомляє про помилку і завершується, залишаючи файл без змін. Помилка запису також виводиться користувачу; код завершення при помилці — `1`.

Файл із контактами та тимчасові файли виключено через `.gitignore`. У репозиторії й ZIP немає збереженої адресної книги. `pickle` призначено для власного локального файлу: не завантажуйте ним файли з невідомих джерел.

## Команди

| Команда | Дія |
| --- | --- |
| `hello` | Привітання від бота. |
| `add name phone` | Створити контакт або додати ще один телефон. |
| `change name old_phone new_phone` | Змінити конкретний телефон контакту. |
| `phone name` | Показати всі телефони контакту. |
| `all` | Показати всі контакти, телефони та дні народження. |
| `add-birthday name DD.MM.YYYY` | Додати або оновити день народження. |
| `show-birthday name` | Показати день народження контакту. |
| `birthdays` | Показати найближчі привітання, згруповані за датами. |
| `close` або `exit` | Завершити роботу та зберегти книгу. |

Телефон має містити рівно 10 цифр від `0` до `9`; дата — календарно правильне значення у форматі `DD.MM.YYYY`. Помилки введення обробляються через `@input_error`. Команди й пошук контактів не залежать від регістру, а написання імені зберігається. Ім'я в CLI вводиться одним словом.

Найближчі дні народження рахуються за сім календарних днів: сьогодні та наступні шість. Привітання у вихідні переносяться на понеділок; для 29 лютого у невисокосному році використовується 28 лютого. Враховується перехід року.

## Перевірка між двома запусками

Перший запуск — введіть команди по черзі:

```text
add John 0501234567
add John 0671234567
add-birthday John 29.02.2000
exit
```

Знову виконайте `python main.py` та введіть:

```text
phone john
show-birthday John
all
close
```

Бот покаже обидва номери `0501234567; 0671234567` та дату `29.02.2000` з попереднього сеансу.

## Автоматичні перевірки

З папки проєкту:

```console
python -m unittest discover -s tests -v
```

Перевірки працюють у тимчасових папках і не змінюють вашу адресну книгу.
